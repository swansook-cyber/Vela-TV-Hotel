# Vela TV Hotel — Ao Nang Fiore Resort

## Purpose
Separate hotel-grade Android TV / Google TV launcher for guest-room televisions, inspired by the accepted Vela TV Launcher v4.0.0 but independently packaged and signed. The home Vela TV app remains untouched.

## V0.1 Foundation
- Original resort welcome UI, room-independent branding, D-pad/OK/Back navigation.
- Guest-facing app shortcuts, with configuration isolated from administrator settings.
- Photo slideshow and silent looping H.264 MP4 background; pause and release video playback whenever launcher is not foreground.
- Server-managed manifest/playlist from Vela Home Hub via HTTPS with integrity checks; cached, atomically activated media for offline continuity.
- Device enrollment by admin, per-room identifiers, scoped read-only device tokens, authenticated admin portal, and no secrets in repository or APK.
- Safe content fallbacks and storage quotas; media downloads asynchronous, metered concurrency and bounded decoding.
- Explicit rollback/test process for TV launcher behavior across Android TV and Google TV.

## Architecture
- Android application: a separate applicationId, signing identity and icon from `net.velalab.tvlauncher`.
- Backend: a separate Hotel API and web admin service, isolated from existing Home Hub services; private upload storage and read-only authenticated media endpoints.
- Distribution: pilot on one television only, before fleet rollout. Cloudflare HTTPS hostname and server port to be selected after existing-service review; do not expose admin without authentication.

## V0.1 acceptance gates
1. Build, unit tests and signing verification.
2. Real-device D-pad, OK, Back, and focus navigation.
3. App launch and returning Home after leaving a guest app.
4. Silent video loop and slideshow, with smooth controls and no background playback.
5. Offline launch with cached assets and no broken empty screen.
6. Restart/boot test and memory/performance test for 30 minutes.
7. Auth isolation, access control, no hardcoded hotel secrets, and a documented restoration path to stock Home.

## Explicit exclusions
No guest personal data, login to guest services, room billing, payment, ads, tracking, remote reboot, system launcher disable or automatic deploy in V0.1.

## Change controls
Do not merge to main, modify the accepted Vela TV v4, deploy to the Home Hub, or roll out to guest rooms without explicit approval.
